# MacBook Air M2 — 16 GB

Reference starting profile for the repository's llama.cpp launcher.

> **Status:** starting configuration, not a completed qualification report.
> The command must be checked against the exact GGUF, llama.cpp version,
> workload, and current memory headroom before being treated as a measured
> recommendation.

## Starting model sizes

- Qwen3.6-35B-A3B UD-IQ2_XXS (about 10.8 GB) or UD-Q2_M (about 11.5 GB)

These examples describe a size class, not a model-quality ranking. Confirm the
exact repository, file, revision, and chat template before downloading.

## Starting command

```sh
llama-server \
  -hf unsloth/Qwen3.6-35B-A3B-GGUF:UD-IQ2_XXS \
  --offline \
  --port 8080 \
  -ngl 99 \
  -fa 1 \
  --cache-type-k q8_0 \
  --cache-type-v q8_0 \
  -b 512 \
  -ub 512 \
  -c 16384 \
  --jinja
```

## Why these values are conservative

- `-c 16384` limits the initial context target on a 16 GB machine.
- `-b 512 -ub 512` keeps batch memory smaller than the larger reference lane.
- `--cache-type-k/v q8_0` retains a higher-precision KV-cache representation;
  measure lower-memory options separately.

Use the [runtime tuning and qualification guide](../../docs/tuning.md) before
changing one setting at a time for a real workload.
