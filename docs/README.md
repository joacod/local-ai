# Shared documentation

These notes explain local-model concepts that apply across runtimes. They are
for learning the vocabulary needed to choose an artifact and start a server.

- [Getting started](./getting-started.md) — the path from an Apple Silicon Mac
  to a local server
- [Terminology](./terminology.md) — models, artifacts, quantization, context,
  memory, and serving terms
- [Hugging Face and model artifacts](./hugging-face.md) — repositories, files,
  revisions, and compatibility
- [Practical performance](./performance.md) — the few memory and size ideas
  needed before choosing a model

For commands, use the [runtime guides](../README.md#choose-a-runtime). For
artifacts actually used in this repository, see the [local model notes](../local-models/).
