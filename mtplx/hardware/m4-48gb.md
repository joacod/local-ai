# MacBook Pro M4 Max — 48 GB

Known-working MTPLX baseline for this Mac. This is not an optimized profile
and contains no benchmark or tuning result.

## Tested configuration

- Hardware: Apple M4 Max with 48 GB unified memory
- macOS: `26.5.2`
- MTPLX: `2.8.3`
- Model artifact: `Youssofal/Qwen3.8-27B-MTPLX-Optimized-Speed` (see the
  [Qwen 3.8 model notes](../../local-models/qwen38.md) for artifact and
  revision details)
- Server: local at `127.0.0.1:8000`

The complete artifact passed `mtplx inspect` with `can_run: true`,
`support_level: "verified-native"`, and `mtp_supported: "yes"`. The baseline
used no optional thermal control, Burst mode, or manual context, cache,
concurrency, or depth setting.

## Default run that worked

The native command was:

```sh
mtplx start
```

MTPLX selected the verified Qwen model, the `turbo` profile, and `turbo MTP`
serving. The server reported:

| Setting | Observed value | Classification |
| --- | --- | --- |
| Profile | `turbo` / `native_mtp_turbo` | MTPLX-selected default |
| Generation mode | `mtp` | Verified at runtime |
| `load_mtp` | `true` | Verified at `/health` |
| `mtp_enabled` | `true` | Verified at `/health` |
| MTP depth | `3` | MTPLX default reported by `/health` and request stats |
| API model ID | `mtplx-qwen38-27b-optimized-speed` | Returned by `/v1/models` |
| API base URL | `http://127.0.0.1:8000/v1` | Local-only server |

A non-streaming OpenAI-compatible chat request with `enable_thinking: false`,
a 32-token response cap, and one active request returned `MTPLX is ready.`
with `finish_reason: "stop"`. Its response stats reported
`runtime_mtp_enabled: true` and `draft_head_installed: true`, confirming that
the request used MTP rather than only loading the MTP weights.

## Verification commands

Use the [MTPLX guide](../README.md) for installation and the complete smoke-test
request. The checks for this profile are:

```sh
MODEL="Youssofal/Qwen3.8-27B-MTPLX-Optimized-Speed"
mtplx inspect "$MODEL" --json
mtplx start

curl -fsS http://127.0.0.1:8000/health
curl -fsS http://127.0.0.1:8000/v1/models
```

Stop the server with:

```sh
mtplx stop
```

## Classification and next steps

This note records a reproducible, known-working baseline only. It does not
claim an optimized profile, throughput result, best depth, or best context.
Do not copy its `turbo` or depth values to another Mac without verification.
Future tuning should be a separate experiment that records the exact workload,
cache state, and runtime settings.
